# SpeakMate 🗣️ — AI 英语口语陪练

一款面向中国市场的买断制 AI 英语口语陪练桌面应用。支持 6 大场景、实时语法纠正、AI 评分、语音朗读。

## 快速开始

```bash
cd ~/speakmate
./start.sh
```

然后在浏览器中打开 `app/index.html`

## 功能

| 功能 | 说明 |
|------|------|
| 🎭 **6 大场景** | 自由对话、酒店入住、工作面试、旅游英语、商务英语、雅思口语 |
| 📝 **实时纠正** | AI 在对话中自动指出语法和用词错误，以标签形式展示 |
| 📊 **三维评分** | 对话结束后给出流利度、语法、词汇评分 + 改进建议 |
| 🔊 **语音朗读** | 每条 AI 回复可点击朗读，支持自动朗读模式 |
| 🎨 **深色 UI** | 类 ChatGPT 暗色主题，响应式设计 |

## 项目结构

```
speakmate/
├── start.sh          # 一键启动脚本
├── server/           # Python 后端 (FastAPI)
│   ├── main.py       # API 入口 + TTS
│   ├── engine.py     # AI 对话引擎
│   ├── scorer.py     # 评分系统
│   └── config.py     # 配置 + 场景提示词
├── app/              # 前端 (纯 HTML/CSS/JS)
│   └── index.html    # 单页应用
└── README.md
```

## API 文档

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 服务信息 |
| `/health` | GET | 健康检查 |
| `/scenarios` | GET | 场景列表 |
| `/chat` | POST | 发送消息 |
| `/evaluate` | POST | 对话评分 |
| `/tts` | POST | 文字转语音 |

## 技术栈

- **后端**: Python + FastAPI + httpx
- **AI**: DeepSeek Chat API
- **语音**: edge-tts (en-US-JennyNeural)
- **前端**: 原生 HTML/CSS/JS (0 依赖)
- **缓存**: SQLite (对话历史) + 文件 (TTS 音频)
